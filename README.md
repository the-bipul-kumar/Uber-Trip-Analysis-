# Uber Trip Analysis Dashboard | Power BI

## Project Overview
The Uber Trip Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze trip bookings, booking value, trip distance, trip duration, vehicle preferences, payment methods, and pickup and drop-off locations.

The objective is to transform raw trip data into meaningful insights for operational monitoring, demand analysis, and data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization
- KPI Reporting
- Business Intelligence

## Project Objectives
- Analyze total bookings and booking value.
- Identify peak booking hours and high-demand days.
- Compare vehicle types based on booking volume and trip distance.
- Analyze payment methods and day-trip versus night-trip patterns.
- Identify frequently used pickup and drop-off locations.
- Provide detailed trip-level reporting.

## Dashboard Pages

### 1. Overview Analysis
Provides a summary of overall trip performance.

**Key Performance Indicators (KPIs):**
- Total Bookings: 103.7K
- Total Booking Value: $1.6M
- Average Booking Value: $15
- Total Trip Distance: 349K miles
- Average Trip Distance: 3 miles
- Average Trip Time: 16 minutes

**Visualizations:**
- Bookings by payment type
- Day trips versus night trips
- Vehicle type performance
- Daily booking trends
- Frequent pickup and drop-off locations
- Preferred vehicle by pickup location
- Farthest trip analysis

### 2. Time Analysis
Analyzes booking demand across different hours and days.

**Visualizations:**
- Total bookings by pickup time
- Bookings by hour and day of the week
- Daily booking comparison
- Date and city filters

This page helps identify peak-demand periods and lower-activity hours.

### 3. Trip Details
Provides a detailed table for analyzing individual trip records.

**Data Fields:**
- Trip ID
- Pickup Date
- Pickup Hour
- Vehicle Type
- Payment Type
- Number of Passengers
- Trip Distance
- Booking Value
- Pickup Location
- Total Booking Indicator

## Key Insights
- The dashboard displays approximately 103.7K bookings.
- Total booking value is approximately $1.6 million.
- Average booking value is approximately $15.
- Total trip distance is approximately 349K miles.
- Booking demand increases during the morning and remains relatively high through the afternoon.
- Weekend booking volumes are high in the displayed weekday comparison.
- UberX has the highest booking volume among the vehicle types shown.
- Penn Station/Madison Square West and Upper East Side North are among the frequent locations displayed.

*Figures and insights should be validated against the underlying dataset.*

## Business Value
- Supports KPI monitoring and operational reporting.
- Identifies booking trends across hours and days.
- Helps compare vehicle-category performance.
- Highlights frequently used pickup locations.
- Enables detailed trip-level analysis.
- Supports data-driven operational decisions.
